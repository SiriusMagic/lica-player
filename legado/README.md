# Legado: Stone 1.3.2

Aquí está el código de **Stone 1.3.2**, la versión de referencia de la app: su aspecto (pingüino, íconos, colores) y sus funciones se pasan a la app actual, que está en [`../stone/`](../stone) y usa la base de Lica, que gasta menos batería y memoria. **Esta carpeta no forma parte de la app**: es solo referencia. Ver [`stone/LEEME-SREN.md`](stone/LEEME-SREN.md).

Las versiones anteriores (Sren Kotlin, Sren-source, Sren Flutter, Aura Player) se eliminaron. Su código sigue guardado en la etiqueta de git **`legado-2026-10`**: `git checkout legado-2026-10 -- legado/`.

## Reglas
- No se edita para añadir funciones: lo nuevo se hace en `stone/`.
- Lo que se pasa a la app se anota en [`../docs/VERSIONES.md`](../docs/VERSIONES.md).
